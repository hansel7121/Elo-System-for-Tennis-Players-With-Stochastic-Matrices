# Elo-System-for-Tennis-Players-With-Stochastic-Matrices

Project by Apollo Capital and Research at New York University.

This project focuses on using linear algebra concepts, stochastic matrices specifically, to create an elo rating system for professional tennis players. This model will be used to predict outcomes in tennis matches. We hope to make this model applicable to any other 1v1 sport.
